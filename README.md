# Aplikasi Profil Mahasiswa

Aplikasi Android sederhana untuk mengelola dan menampilkan data profil mahasiswa menggunakan **Kotlin** dan **Jetpack Compose**.

## Deskripsi

Aplikasi ini dibuat sebagai tugas perkuliahan untuk menerapkan penggunaan komponen UI pada Android menggunakan Jetpack Compose. Aplikasi menyediakan formulir untuk mengisi data mahasiswa dan menampilkan hasil setelah data berhasil disimpan.

## Fitur Aplikasi

- Input nama lengkap mahasiswa.
- Input Nomor Induk Mahasiswa (NIM).
- Input program studi.
- Input semester.
- Validasi data agar semua kolom wajib diisi.
- Validasi semester dengan rentang angka 1–14.
- Tombol Simpan untuk menyimpan dan menampilkan data profil.
- Tombol Reset untuk mengosongkan formulir.
- Pesan status berhasil atau gagal.

## Teknologi yang Digunakan

- **Bahasa Pemrograman:** Kotlin
- **Framework UI:** Jetpack Compose
- **Material Design:** Material 3
- **IDE:** Android Studio

## Tampilan Aplikasi

Aplikasi memiliki beberapa bagian utama:
1. Header dengan logo Universitas Merdeka Pasuruan.
2. Formulir data mahasiswa.
3. Tombol Simpan dan Reset.
4. Pesan status penyimpanan.
5. Kartu hasil profil mahasiswa yang telah disimpan.
